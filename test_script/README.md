# Запуск тестов

Тесты используют исходный `ImageProcessorTester` и `TestCase(input, name, args, eps)` из примера: программа запускается с аргументами, выходной BMP сравнивается с эталоном, результат выводится как `OK` / `FAIL`.

Нужны Python 3 и Pillow (`python3 -m pip install Pillow`).

Из корня проекта:

```sh
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build -j 2
python3 test_script/test_image_processor.py ./build/image_processor
```

Либо через CTest:

```sh
ctest --test-dir build --output-on-failure
```

Пути к эталонам определяются относительно скрипта, поэтому тесты можно запускать из другой папки.

## Проверки

- Все 16 исходных TestCase сохранены. Шесть проверок `flag` используют предоставленные BMP-эталоны.
- Для 10 исходных проверок `lenna` отсутствуют входной BMP и эталоны. Они явно выводятся как `SKIP`, а не засчитываются как пройденные. Чтобы включить их, поместите оригинальные `lenna*.bmp` в `test_script/data`. Пропуски отражаются в итоговом счётчике; сами по себе они не делают код возврата ненулевым.
- Добавлены 98 проверок изображений: базовые фильтры, повторные применения, порядок фильтров, crop за границами, одиночный пиксель, одна строка/колонка, размытие с разными sigma, сохранение белого изображения фильтром glass.
- Добавлены 35 проверок справки, неверных аргументов, ошибок файлов и повреждённых BMP. Завершение по сигналу считается провалом, для обработанной ошибки требуется сообщение в stderr.

Дополнительные эталоны создаются `reference_images.py` во временной папке независимо от проверяемой программы, по формулам фильтров. Исходные эталоны не перезаписываются. Для Gaussian Blur используется прямая двумерная свёртка нормированным дискретным ядром с радиусом 3σ; это выбранная проектом аппроксимация, а не замена оригинальных эталонов `lenna`. Проверка авторского glass ограничена сохранением белого изображения.

Сравнение проверяет размеры, RGB-режим и RMS по всем трём каналам. В исходном примере учитывался только первый канал гистограммы. Скрипт продолжает остальные проверки после провала и возвращает ненулевой код при любой ошибке.
